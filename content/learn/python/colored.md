##### [Termcolor (Simple)](https://pypi.org/project/termcolor/)

```python
from termcolor import colored
print(colored('Hello World', 'green'))
print(colored('Hello World', 'cyan', 'on_magenta', attrs=['blink', 'bold']))
```
