An `object` in JavaScript is similar to a class in C++.

```javascript
var person = {
    firstName: "Dalton",
    middleName: "Russell",
    lastName: "Cole",
    fullName: function() {
        return `${firstName:} ${middleName:} ${lastName:}`;
    }
}; // <- DON'T FORGET THE ;
```
