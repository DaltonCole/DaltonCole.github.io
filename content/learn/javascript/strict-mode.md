+++
title = "Strict Mode"
+++

Strict mode forces the programmer to code properly (in a matter of speaking). It removes some older parts of JavaScript. Check [this](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Strict_mode) for more details.

To enable strict mode, add this to the top of the JavaScript file or function body:

```javascript
'use strict';
```
