Allows you to enter commands. To enter type <kbd>:</kbd>. This is technically a mode, but I thought it important enough to be a full subject.

Useful things to do in command mode:

- <kbd>:w</kbd>: Write. Save file.
- <kbd>:q</kbd>: Quit
- <kbd>:wq</kbd>: Write and then quit
- <kbd>:!q</kbd>: Force quit. Lets you quit without saving.
- <kbd>.</kbd>: Repeat last command
- `:s/FIND/REPLACE/g`: Find an replace text on current line
- `:%s/FIND/REPLACE/g`: Find an replace text in entire document
