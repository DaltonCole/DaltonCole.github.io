Insert mode allows you to add text to a file. To enter insertion mode, type <kbd>i</kbd> from normal mode.

Useful other ways to enter insert mode:

- <kbd>Shift</kbd> + <kbd>a</kbd>: Start insert at end of line
- <kbd>Shift</kbd> + <kbd>i</kbd>: Start insert at beginning of line
- <kbd>a</kbd>: Insert after cursor
- <kbd>o</kbd>: Add a new line below the current line and insert there
- <kbd>Shift</kbd> + <kbd>O</kbd>: Add a new line above the current line and insert there
