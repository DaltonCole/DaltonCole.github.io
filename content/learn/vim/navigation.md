Navigation (normal mode):

- <kbd>gg</kbd>: Go to start of file
- <kbd>G</kbd>: Go to last line in file
- <kbd>Ctrl</kbd> + <kbd>o</kbd>: Go to old cursor position (history is kept)
- <kbd>Ctrl</kbd> + <kbd>i</kbd> OR <kbd>Tab</kbd>: Go to newer cursor position
- <kbd>0</kbd> or <kbd>^</kbd>: Go to beginning of line
- <kbd>$</kbd>: Go to end of line
- <kbd>w</kbd>: Beginning of next word
- <kbd>e</kbd>: End of current word
- <kbd>b</kbd>: Beginning of current word
- <kbd>Enter</kbd>: Beginning of next line
- `Number` + `hjkl`: Jump that many lines/characters
