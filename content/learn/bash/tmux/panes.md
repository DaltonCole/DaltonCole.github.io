title = "Panes"
+++

- <kbd>Alt</kbd> + <kbd>← ↑ → ↓</kbd>: Switch to pane
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>v</kbd>: Split plane vertically
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>s</kbd>: Split plane horizontally
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>{</kbd>: Move the current pane left
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>}</kbd>: Move the current pane right
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>Space</kbd>: Toggle between pane layouts
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>z</kbd>: Pane zoom
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>!</kbd>: Convert pane into a window
- <kbd>Ctrl</kbd> + <kbd>b</kbd> + <kbd>← ↑ → ↓</kbd>: Resize pane. Hold down the first to keys and tap the arrow key
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>x</kbd>: Close current pane
