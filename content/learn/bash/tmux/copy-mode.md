+++
title = "Copy Mode"
+++

- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>\[</kbd>: Enter copy mode
- Use vim navigation keys or arrow keys to move around
- <kbd>Space</kbd>: Start selecting
- <kbd>Esc</kbd>: Clear selection
- <kbd>Enter</kbd>: Copy selection
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>\]</kbd>: Paste
