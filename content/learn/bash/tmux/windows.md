- <kbd>Shift</kbd> + <kbd>← →</kbd>: Switch to window
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>c</kbd>: Create a new window
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>,</kbd>: Rename window
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>&</kbd>: Close current window
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>0</kbd> ... <kbd>9</kbd>: Select a window by number
- <kbd>Ctrl</kbd> + <kbd>b</kbd>, <kbd>:</kbd> `:swap-window -s <source window number > -t <target window number>`: Create a new window
