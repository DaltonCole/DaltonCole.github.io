Command history can be gone through via the <kbd>↑↓</kbd>. In the middle of your history? Use <kbd>Ctrl</kbd> + <kbd>c</kbd> to get back to the start!

Here are some commands to further explore your bash history:

- <kbd>Alt</kbd> + <kbd>r</kbd>: Revert command pulled from history to its original form (undo changes to command)
- <kbd>Ctrl</kbd> + <kbd>r</kbd>: Recall (search) for the last instance of a command
  - <kbd>Enter</kbd>: Run the searched command
  - <kbd>Ctrl</kbd> + <kbd>g</kbd>: Leave the search without running a command
