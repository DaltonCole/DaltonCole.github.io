Manage running processes

- <kbd>Ctrl</kbd> + <kbd>c</kbd>: Kill the current running process
- <kbd>Ctrl</kbd> + <kbd>z</kbd>: Suspends the current running process and moves it to the background
  - Use `bg` to start the process in the background
  - Use `jobs` and `fg %<Number>` to bring it back to the foreground
- <kbd>Ctrl</kbd> + <kbd>d</kbd>: Send the EOF (End-Of-File) marker. If in bash, the terminal will exit
